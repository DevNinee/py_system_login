# Login GUI em Python

Este projeto começou como uma **interface gráfica de login simples** desenvolvida em **Python** utilizando o **Tkinter**.  
Ele foi criado com fins educacionais e como base para sistemas maiores que exigem autenticação de usuário.

---

## Evolução do Projeto
O sistema de login está em constante evolução.  
- A versão atual utiliza **Tkinter** para criar uma interface desktop.  
- A próxima etapa será **refazer o sistema em Django**, transformando-o em uma aplicação web completa, com autenticação robusta, integração com banco de dados e suporte a múltiplos usuários.

## Funcionalidades (versão Tkinter)
- Interface gráfica simples e responsiva.
- Validação de usuário e senha.
- Mensagens de sucesso ou erro com `messagebox`.
- Simulação de painel após login.
- Uso de cores personalizadas e organização por frames.

---

## Melhorias Futuras
- Integração com banco de dados (SQLite ou PostgreSQL).
- Cadastro de novos usuários.
- Sistema de recuperação de senha.
- Responsividade para diferentes resoluções.
- **Migração para Django**:
  - Autenticação com `django.contrib.auth`.
  - Painel administrativo para gerenciamento de usuários.
  - Integração com outros projetos web.
  - Possibilidade de hospedar em nuvem e abrir para acesso público.
